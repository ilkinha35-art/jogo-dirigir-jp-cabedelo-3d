# Jogo de Dirigir - João Pessoa & Cabedelo (3D)

Simulador 3D simples de direção pelas ruas de João Pessoa e Cabedelo, com ônibus Navegantes e Unitrans.

## Tecnologias
- Engine: Godot 4 (sem Unity/Blender)
- Linguagem: GDScript
- Mapas: OpenStreetMap simplificado

## Como jogar
1. Clone este repositório
2. Abra no Godot 4
3. Execute a cena `scenes/joao_pessoa.tscn`

## Objetivo
Dirigir pelas ruas respeitando o trânsito e interagir com ônibus locais
